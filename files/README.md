# Files

Put any design files here: CAD models, drawings, cut files (DXF, SVG),
3D-print files (STL), code, spreadsheets, data. They're listed automatically on
your site's How it works page.

If you can, include both the file you worked in (so others can edit it) and a
version anyone can open (PDF, STEP, DXF, STL).

Keep each file under 50 MB. Put video on YouTube or Vimeo and link it.
